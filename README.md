# Better pager

A better pager (virtual desktop switcher) for the KDE Plasma desktop (v6).

## Usage

- After you change anything, rebuild the package with
  ```bash
  ./bundle.sh
  ```

## Development

- Install the `plasma-sdk` package. Then you can use
  ```bash
  plasmoidviewer -a ./package
  ```
  to test the plasmoid in a sandbox environment.
